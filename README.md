## Использование

```sh
tetosays [OPTIONS] [TEXT]
```

| Флаг | Что делает |
| ---- | ---------- |
| `[TEXT]...` | Текст в облачке, несколько слов склеиваются через пробел. Многострочность — через настоящий перевод строки (`tetosays $'line1\nline2'`) или stdin. Литеральный `\n` в обычных кавычках НЕ разворачивается. Без аргумента и без stdin — случайный kasem tetum (`-` = принудительно stdin, там kasem tetum не подставляется) |
| `-k, --kasem [<N>]` | Kasem tetum вместо TEXT (опционально число слов 1–500, по умолчанию 30). Бьёт TEXT и stdin |
| `-s, --style <STYLE>` | Арт по номеру (см. `--list`). Без флага — случайный из пула |
| `-l, --list` | Показать все стили с превью |
| `-w, --width <WIDTH>` | Ширина пузыря: точное число 10–200 или `auto` (по умолчанию `auto` — впритык к тексту до ~64 колонок, дальше врап с пропорцией ~4:1 (у багета ~12:1); если по пропорции не влезает в высоту экрана — расширяется, влезть важнее; на tty всё равно не шире экрана). Явный `-w` бьёт авто |
| `-b, --bubble <STYLE>` | Стиль пузыря: `round` (по умолчанию, `╭─╮`), `sharp` (`┌─┐`), `double` (`╔═╗`), `heavy` (`┏━┓`), `star` (`***`), `dots` (`·┄·`), `baguette` (багет с крошками), `ascii` (`+--+`), `cowsay` (классика `< > / \`), `think` (`(...)` с хвостом `o`) |
| `-B, --no-bubble` | Без пузыря: голый текст над артом (бьёт `--bubble`) |
| `-n, --no-wrap` | Не переврапливать: пробелы/отступы/переносы как есть (для `figlet`, таблиц). Длинные строки жёстко режутся по ширине |
| `-F, --flip` | Отразить арт по горизонтали (брайль зеркалится по точкам, `/ ↔ \`, скобки меняются) |
| `--bold` | Жирный вывод (без короткого флага — `-b` занят пузырём). Уважает `NO_COLOR` |
| `-r, --rainbow` | Радужный градиент текста и арта. Уважает `NO_COLOR` |
| `-A, --animate [<SEC>]` | Переливающаяся радуга текста и арта на tty (~12 fps, бьёт `--rainbow`; без tty — один статичный кадр). Без числа — 5 сек, `0` — пока не нажмёшь Ctrl-C. Если кадр не влезает в экран — один статичный кадр. Уважает `NO_COLOR` |
| `-a, --all` | Показать текст со всеми стилями из пула подряд (игнорирует `-s`) |
| `--align <ALIGN>` | Выравнивание: `center`, `left`, `right` (по умолчанию `center`; в пайпах всегда без отступа от края) |
| `--reserve <N>` | Строк резерва снизу под промпт/статус (бьёт `TETOSAYS_RESERVE_ROWS`, по умолчанию 3) |
| `--no-clear` | Не чистить экран (по умолчанию чистит на tty) |
| `--disable <N...>` | Убрать стили из рандомного пула через запятую или повтором флага (`--disable 1,2`, `--disable 1 --disable 2`). Через `-s` всё равно доступны |
| `--enable <N...>` | Вернуть стили в пул, формат как у `--disable` (бьёт дефолтные исключения и `--disable`) |

Примеры:

```sh
tetosays hi -s 1
tetosays hello world
tetosays $'line1\nline2'
echo "hello" | tetosays --align left
printf 'line1\nline2\n' | tetosays
fortune | tetosays
tetosays "x" --disable 6 --enable 3
tetosays hi -b think
tetosays hi -b cowsay -s 1
echo "hello" | tetosays -B
figlet TETO | tetosays -n
tetosays hi -F -s 3
tetosays hi --bold -r
tetosays hi -r -A
tetosays hi -a
tetosays
tetosays -k
tetosays -k 10
```

Замечание: по умолчанию пробелы и табы в тексте схлопываются (word wrap как в cowsay) — колончатый вывод `ls -l`, `df` и таблицы с выравниванием не сохранят отступы. С флагом `-n, --no-wrap` текст идёт как есть.

Вывод всегда занимает всю высоту терминала и центрируется вертикально (в пайпах — без вертикального паддинга и центрирования по ширине терминала).

Стиль 6 исключён из случайного пула по умолчанию — 105 строк, не влезает в маленькие терминалы. Доступен через `-s 6`, вернуть в пул можно флагом `--enable 6`.

Цвета (`--bold`, `-r`) уважают переменную окружения `NO_COLOR` — если она выставлена, вывод без ANSI-кодов. Нюанс Konsole: жирный брайль там красится в синий самой консолью (опция «рисовать насыщенные цвета жирным», `BoldIntense`), это не баг тетосейса — проверяется через `printf '\x1b[1m⠿ hello\x1b[0m\n`.

## Свои арты

Кидай `.txt` файлы в `~/.config/tetosays/arts/` (или `$XDG_CONFIG_HOME/tetosays/arts/`). Каждый файл — новый стиль с номером после встроенных, сортировка по имени файла. Пустые файлы и не-`.txt` игнорируются.
