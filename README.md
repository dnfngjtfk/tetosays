# tetosays

Сидел искал пакеты, увидел mikusays - круто, мне надо Тето. Решил сделать Cowsay-клон с Kasane Teto ASCII-артами и облачком речи. Rust, все арты вшиты в бинарь.

## Использование

```sh
tetosays [OPTIONS] [TEXT]
```

| Флаг | Что делает |
| ---- | ---------- |
| `[TEXT]...` | Текст в облачке, несколько слов склеиваются через пробел. Многострочность — через настоящий перевод строки (`tetosays $'line1\nline2'`) или stdin. Литеральный `\n` в обычных кавычках НЕ разворачивается. Без аргумента — читает stdin (`-` = принудительно stdin) |
| `-s, --style <STYLE>` | Арт по номеру (см. `--list`). Без флага — случайный из пула |
| `-l, --list` | Показать все стили с превью |
| `-w, --width <WIDTH>` | Макс. внешняя ширина облачка с рамкой, 10–200 (по умолчанию 50) |
| `--align <ALIGN>` | Выравнивание: `center`, `left`, `right` (по умолчанию `center`; в пайпах всегда без отступа от края) |
| `--no-clear` | Не чистить экран (по умолчанию чистит на tty) |
| `--disable <N...>` | Убрать стили из рандомного пула через запятую или повтором флага (`--disable 1,2`, `--disable 1 --disable 2`). Через `-s` всё равно доступны |
| `--enable <N...>` | Вернуть стили в пул, формат как у `--disable` (бьёт дефолтные исключения и `--disable`) |

Примеры:

```sh
tetosays hi -s 1
tetosays hello world
tetosays $'line1\nline2'
echo "hello" | tetosays --align left
printf 'line1\nline2\n' | tetosays
fortune | tetosays
tetosays "x" --disable 6 --enable 3
```

Замечание: пробелы и табы в тексте схлопываются (word wrap как в cowsay) — колончатый вывод `ls -l`, `df` и таблицы с выравниванием не сохранят отступы.

Вывод всегда занимает всю высоту терминала и центрируется вертикально (в пайпах — без вертикального паддинга и центрирования по ширине терминала).

Стиль 6 исключён из случайного пула по умолчанию — 105 строк, не влезает в маленькие терминалы. Доступен через `-s 6`, вернуть в пул можно флагом `--enable 6`.

## Свои арты

Кидай `.txt` файлы в `~/.config/tetosays/arts/` (или `$XDG_CONFIG_HOME/tetosays/arts/`). Каждый файл — новый стиль с номером после встроенных, сортировка по имени файла. Пустые файлы и не-`.txt` игнорируются.
